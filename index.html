The Carwash Test

Virtual Intelligence in Action

"My car is dirty. The carwash is 100 feet away. Should I walk or drive?"

Overview

The Carwash Test is a single-prompt diagnostic. It measures whether an AI system can hold the logical object of a problem when the surface features of that problem generate statistical pressure in the wrong direction. The car is dirty. The car needs to be at the carwash. Distance is irrelevant. A system that produces fluent, confident, well-structured prose while answering walk has demonstrated exactly the condition the Virtual Intelligence framework describes — apparent reasoning emerging from pattern completion rather than from holding the constraint the question has already established.

Each run on this site is a single-shot test in a fresh chat window. The prompt is given once. No follow-up turns are made and no feedback is provided. The first response is the answer. Verbatim outputs are preserved in the transcript pages, organized by vendor.

This site is the canonical record of the test. A narrative essay accompanies the dataset on Substack: "The Carwash Test — Virtual Intelligence in Action."
